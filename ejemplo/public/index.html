Que puede y que no puede

Puede

  • Describir acciones en lenguaje natural (act).
  • Extraer data con schema (extract + Zod).
  • Resolver layouts cambiantes o desconocidos.
  • Combinar con Playwright para asserts.

No puede

  • Garantizar 100% determinismo en UI dinamica.
  • Reemplazar tests de regresion estables.
  • Evitar costo de LLM (tokens).
  • Ser mas rapido que un selector directo.

Especificaciones tecnicas (demo)

Dependencias

  • @browserbasehq/stagehand
  • @playwright/test (dev)
  • zod, dotenv

Entorno

  • Node LTS recomendado
  • Playwright browsers instalados
  • Env: LOCAL o BROWSERBASE

Salida

  • Logs en consola
  • Reporte HTML local
  • Playwright report + traces

Consideraciones clave

Lo que tener en cuenta antes de adoptar Stagehand en produccion.

Costo y latencia

  • Cada act/extract consume tokens.
  • Mayor latencia que selectores directos.
  • Medir costo por run en workflows grandes.

Confiabilidad

  • UI dinamica puede cambiar el resultado.
  • Usar Playwright para asserts criticos.
  • Iterar prompts cuando el layout cambia.

Seguridad y datos

  • Evitar enviar datos sensibles al modelo.
  • Revisar logs y reportes compartidos.
  • Definir politicas de retencion.

Stagehand + Playwright (combo ganador)

Cuando mezclar IA con pasos deterministas.

1

Stagehand

Para UI ambigua, cambios de layout o busquedas humanas.

2

Playwright

Para selectores estables, asserts y performance.

3

Hibrido

IA para llegar, Playwright para validar.

const page = stagehand.page; await page.goto(todoUrl); await page.fill("#todo-input", "Lavar auto"); await page.click("#add-btn"); await page.act("marca como completada la tarea 'Lavar auto'"); await expect(page.locator("li.todo-item.done")).toHaveCount(1);

Reportes y trazas

Stagehand report

Inference logs + resultados en HTML.

npm run report npm run report:serve

Playwright report

HTML report + Trace Viewer para revisar pasos.

npm run test:pw npm run test:pw:report npm run test:pw -- --trace on npx playwright show-trace test-results/**/trace.zip

Requisitos para que funcione

npm install npx playwright install # Keys en .env OPENAI_API_KEY=... ANTHROPIC_API_KEY=...
Para Browserbase: configurar BROWSERBASE_API_KEY y BROWSERBASE_PROJECT_ID. En local se usa el navegador local.

Checklist antes del live
