🎭 Stagehand

Browser Automation con IA

Atenea Conocimientos | 2026

😤 El Problema

Selenium / Playwright

  • Selectores frágiles
  • Se rompen con cambios de UI
  • Mucho código boilerplate

Agentes de IA puros

  • Impredecibles
  • Costosos (muchos tokens)
  • Lentos

✨ La Solución: Stagehand

Lo mejor de ambos mundos:

  • Código cuando sabés qué hacer
  • IA cuando necesitás flexibilidad
  • Caching para no repetir inferencias

🔧 Los 3 Métodos Clave

Método Uso Ejemplo
act() Acciones simples "click en Login"
extract() Extraer datos "obtener precio"
agent() Tareas complejas "completar el checkout"

🎯 act() - Acciones Simples


// Navegar a una página
await page.goto("https://github.com");

// Ejecutar una acción con lenguaje natural
await stagehand.act("click en el botón Sign in");

// Otra acción
await stagehand.act("escribir 'mi-usuario' en el campo username");

📊 extract() - Obtener Datos


import { z } from "zod";

// Definir el schema de lo que queremos
const schema = z.object({
  titulo: z.string(),
  precio: z.number(),
  disponible: z.boolean()
});

// Extraer datos estructurados
const producto = await stagehand.extract(
  "extraer información del producto",
  schema
);

console.log(producto);
// { titulo: "iPhone 15", precio: 999, disponible: true }

🤖 agent() - Tareas Complejas


// Crear un agente para tareas de múltiples pasos
const agent = stagehand.agent({
  provider: "anthropic",
  model: "claude-sonnet-4-20250514"
});

// Ejecutar una tarea compleja
await agent.execute(
  "Buscar el producto más vendido, agregarlo al carrito, " +
  "y llegar hasta la página de checkout"
);

⚡ Auto-Caching

Primera ejecución

  • LLM analiza la página
  • Encuentra el elemento
  • Guarda en cache

Siguientes ejecuciones

  • Usa el cache
  • Sin llamadas al LLM
  • Súper rápido 🚀

🔄 Self-Healing

Cuando el sitio cambia:

  1. Stagehand detecta que el selector cacheado falló
  2. Automáticamente vuelve a usar IA
  3. Encuentra el nuevo elemento
  4. Actualiza el cache

¡Tus tests no se rompen! 🎉

📝 Ejemplo Completo


import { Stagehand } from "@browserbasehq/stagehand";
import { z } from "zod";

const stagehand = new Stagehand({ env: "LOCAL" });
await stagehand.init();

const page = stagehand.context.pages()[0];
await page.goto("https://news.ycombinator.com");

// Extraer los top posts
const posts = await stagehand.extract(
  "extraer los primeros 5 posts con título y puntos",
  z.object({
    posts: z.array(z.object({
      titulo: z.string(),
      puntos: z.number()
    }))
  })
);

console.log(posts);
await stagehand.close();
