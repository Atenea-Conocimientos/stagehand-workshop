🎭 Stagehand

Browser Automation con IA

Atenea Conocimientos | 2026

😤 El Problema

Selenium / Playwright

  • Selectores frágiles
  • Se rompen con cambios de UI
  • Mucho código boilerplate

Agentes de IA puros

  • Impredecibles
  • Costosos (muchos tokens)
  • Lentos

✨ La Solución: Stagehand

Lo mejor de ambos mundos:

  • Código cuando sabés qué hacer
  • IA cuando necesitás flexibilidad
  • Caching para no repetir inferencias

🔧 Los 3 Métodos Clave

Método Uso Ejemplo
act() Acciones simples "click en Login"
extract() Extraer datos "obtener precio"
agent() Tareas complejas "completar el checkout"

🎯 act() - Acciones Simples


const stagehand = new Stagehand({ env: "LOCAL" });
await stagehand.init();
const page = stagehand.page;

await page.goto("https://github.com");
await page.act("click en el botón Sign in");
await page.act("escribir 'mi-usuario' en el campo username");

📊 extract() - Obtener Datos


import { z } from "zod";

const schema = z.object({
  titulo: z.string(),
  precio: z.number(),
  disponible: z.boolean()
});

const producto = await page.extract({
  instruction: "extraer información del producto",
  schema
});

console.log(producto);

🤖 agent() - Tareas Complejas


const agent = stagehand.agent({
  provider: "anthropic",
  model: "claude-sonnet-4-20250514"
});

await agent.execute(
  "Buscar el producto más vendido, agregarlo al carrito, " +
  "y llegar hasta la página de checkout"
);

⚡ Auto-Caching

Primera ejecución

  • LLM analiza la página
  • Encuentra el elemento
  • Guarda en cache

Siguientes ejecuciones

  • Usa el cache
  • Sin llamadas al LLM
  • Súper rápido 🚀

🔄 Self-Healing

Cuando el sitio cambia:

  1. Stagehand detecta que el selector cacheado falló
  2. Automáticamente vuelve a usar IA
  3. Encuentra el nuevo elemento
  4. Actualiza el cache

¡Tus tests no se rompen! 🎉

🧩 Stagehand + Playwright

IA para llegar, Playwright para validar.


const page = stagehand.page;
await page.goto(todoUrl);
await page.fill("#todo-input", "Lavar auto");
await page.click("#add-btn");
await page.act("marca como completada la tarea 'Lavar auto'");
await expect(page.locator("li.todo-item.done")).toHaveCount(1);

✅ Qué puede / 🚫 Qué no puede

Puede

  • Describir acciones en lenguaje natural
  • Extraer data con schema (Zod)
  • Resolver layouts cambiantes
  • Combinar con Playwright para asserts

No puede

  • Garantizar 100% determinismo
  • Reemplazar tests estables
  • Evitar costo de LLM
  • Ser más rápido que selectores directos

⚠️ Consideraciones clave

  • Costo y latencia: cada act/extract consume tokens.
  • Confiabilidad: usar Playwright para asserts críticos.
  • Seguridad: evitar datos sensibles en prompts.
  • Observabilidad: guardar reportes y traces.

📝 Ejemplo Completo


import { Stagehand } from "@browserbasehq/stagehand";
import { z } from "zod";

const stagehand = new Stagehand({ env: "LOCAL" });
await stagehand.init();
const page = stagehand.page;

await page.goto("https://news.ycombinator.com");

const posts = await page.extract({
  instruction: "extraer los primeros 5 posts con título y puntos",
  schema: z.object({
    posts: z.array(z.object({
      titulo: z.string(),
      puntos: z.number()
    }))
  })
});

console.log(posts);
await stagehand.close();
